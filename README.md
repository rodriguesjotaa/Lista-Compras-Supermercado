# 🛒 Lista de Compras de Supermercado

Aplicação web simples para gerenciar a lista de compras da semana. Permite adicionar itens, marcar como concluídos e remover quando não forem mais necessários, com feedback visual e layout responsivo (desktop e mobile).

Projeto da disciplina **Programação Front-end – Linguagem de Programação para Web II**, do curso de Sistemas de Informação do Centro Universitário de Volta Redonda (UniFOA).

## ✨ Funcionalidades

- Lista inicial pré-cadastrada (Pão integral, Café, Suco de maracujá, Biscoito de Maizena)
- Adicionar novos itens (o campo é limpo após adicionar)
- Validação de campo vazio com mensagem de erro amigável
- Marcar e desmarcar itens como concluídos (texto riscado e opacidade reduzida)
- Remover itens com o botão de lixeira
- Alerta vermelho na parte inferior ao remover, que some sozinho após alguns segundos ou ao clicar no "X"
- Layout responsivo com CSS Grid (1 coluna no celular, 2 colunas em telas maiores)

## 🛠️ Tecnologias

- HTML5
- CSS3 (Grid Layout e Media Queries)
- JavaScript (vanilla)

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/rodriguesjotaa/lista-compras.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd lista-compras
   ```
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nenhuma dependência.
